### 소개
자연어로 일정에 대해 서술하면 이를 이해하고 일정을 추가해주는 앱입니다. <br/>
일정을 관리함에 있어서 편리하게 일정을 추가하고 관리하고자 제작하였습니다.

### 주요 기능
- 구글 OAuth 로그인
- 자연어로 일정을 추가하기
- 일정 검색
- 일정 캘린더 뷰
